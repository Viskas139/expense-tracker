## Обґрунтування вибору фреймворку (Vue 3)

Для виконання лабораторної роботи було обрано фреймворк **Vue 3** з наступних причин:
1. **Простота інтеграції:** Можливість підключення через CDN без необхідності складної збірки (npm/Webpack/Vite).
2. **Двостороннє зв'язування та реактивність:** Зручна робота з реактивним станом (`data`) та обчислюваними властивостями (`computed`), що автоматично оновлюють UI при зміні даних.
3. **Компонентний підхід:** Легке створення та повторне використання компонентів (наприклад, `ExpenseRow` для відображення транзакцій).
